ST1VAFE3BX Sensor Breakout & Validation Platform

Altium Designer · 4-Layer PCB · Mixed-Signal

Engineered a multi-layer evaluation PCB designed around STMicroelectronics' ST1VAFE3BX biomechanical sensor architecture. Features strict trace impedance matching, full analog ground plane isolation, low-pass RC filter network integration, and dedicated low-noise LDO power decoupling to prevent power rail noise during high-gain sensor validation.

Stackup 4-Layer (SIG-GND-PWR-SIG)
Board Core FR-4 (1.6mm Std)

ADS1292 Low-Noise ECG/EMG Biopotential Acquisition Board

Mixed-Signal · Bio-AFE · Low-Noise PCB

Designed a 2-channel analog front-end acquisition board based on Texas Instruments' ADS1292 24-bit delta-sigma ADC. Built for microvolt-level biopotential signal extraction (ECG/EMG) with integrated Right Leg Drive (RLD) feedback circuitry for common-mode rejection ratio (CMRR) optimization and lead-off detection.

ADC Resolution 24-Bit Delta-Sigma
CMRR Performance > 105 dB with RLD
Sampling Rate 125 SPS to 8 kSPS
Host Communication SPI with DMA Buffer
